## :dart: O guia para alavancar a sua carreira

> O Microsoft Azure é a segunda maior plataforma de nuvem do mundo: mais de 200 serviços para computação, dados, redes, segurança e, cada vez mais, IA generativa (Azure AI Foundry, Azure OpenAI). É a base de infraestrutura de bancos, governos, multinacionais e de uma fatia enorme das vagas de Cloud, DevOps, Administração de Sistemas e Desenvolvimento no Brasil — puxada também pela forte presença do Windows Server, do Active Directory/Entra ID e do Microsoft 365 nas empresas brasileiras. Este guia reúne roadmap, documentação oficial, cursos gratuitos e pagos (em português e em inglês), livros, canais, ferramentas, projetos práticos, certificações reais (do AZ-900 ao AZ-305) e um capítulo dedicado a usar IA (GitHub Copilot, Azure AI Foundry, Semantic Kernel) na prática com Azure — tudo verificado e organizado para quem quer sair do zero e chegar a uma vaga cloud.

## 💡 Nossa proposta

> A proposta deste guia é dar uma ideia sobre o atual panorama e guiá-lo se você estiver confuso sobre qual será o seu próximo aprendizado, sem influenciar você a seguir os 'hypes' e 'trends' do momento. Acreditamos que com um maior conhecimento das diferentes estruturas e soluções disponíveis poderá escolher a ferramenta que melhor se aplica às suas demandas. E lembre-se, 'hypes' e 'trends' nem sempre são as melhores opções.

## :beginner: Para quem está começando agora

> Não se assuste com a quantidade de conteúdo apresentado neste guia. Acredito que quem está começando pode usá-lo não como um objetivo, mas como um apoio para os estudos. <b>Neste momento, dê enfoque no que te dá produtividade e o restante marque como <i>Ver depois</i></b>. Ao passo que seu conhecimento se torna mais amplo, a tendência é este guia fazer mais sentido e ficar fácil de ser assimilado. Bons estudos e entre em contato sempre que quiser! :punch:

## 🤖 IA na prática

O Azure é hoje também uma das maiores plataformas de IA generativa do mercado corporativo: a própria Microsoft oferece ferramentas para aprender mais rápido e para automatizar tarefas do dia a dia de quem trabalha com a nuvem.

**Para aprender**
- Peça para um assistente **explicar um erro de permissão do Azure RBAC** colando a mensagem completa (ex.: `AuthorizationFailed` em uma chamada da CLI) e peça duas formas de corrigir a atribuição de papel sem dar permissão além do necessário.
- Cole a saída de um comando do Azure CLI (ex.: `az vm list -o json`) e peça para o assistente explicar cada campo do JSON retornado.
- Peça **exercícios com gabarito** sobre o serviço que está estudando (ex.: "monte um cenário de rede virtual com sub-redes pública e privada e me pergunte sobre roteamento e NSGs").
- Use o [Microsoft Copilot](https://copilot.microsoft.com/) para tirar dúvidas rápidas sobre conceitos e terminologia antes de ir para a documentação oficial.

**Para trabalhar**
- [GitHub Copilot for Azure](https://learn.microsoft.com/en-us/azure/developer/github-copilot-azure/introduction) — extensão oficial que permite provisionar, depurar e perguntar sobre recursos do Azure em linguagem natural direto do editor.
- [Azure AI Foundry](https://learn.microsoft.com/pt-br/azure/ai-foundry/) — plataforma oficial da Microsoft para construir, avaliar e implantar aplicações e agentes de IA no Azure, incluindo os modelos que antes ficavam sob a marca "Azure OpenAI Service".
- [Semantic Kernel](https://learn.microsoft.com/en-us/semantic-kernel/overview/) — SDK oficial e open source para orquestrar agentes de IA e integrar modelos de linguagem a aplicações .NET, Python e Java.
- Use assistentes de código para gerar templates de **Bicep/ARM/Terraform** — mas sempre rode `az deployment group what-if`/`terraform plan` antes de aplicar qualquer mudança sugerida.

**Limites e boas práticas**
- IA **inventa nomes de serviços, parâmetros e limites de assinatura** que não existem ou que já mudaram (a própria documentação da Microsoft muda de nome com frequência, como aconteceu com o Azure AI Foundry). Confirme sempre na [documentação oficial](https://learn.microsoft.com/pt-br/azure/).
- Nunca cole **chaves de acesso, connection strings, segredos do Key Vault ou dados de clientes** em ferramentas de IA sem a política de segurança da sua empresa.
- Toda infraestrutura sugerida por IA deve passar por revisão humana antes de ir para produção — o custo de um recurso mal configurado no Azure pode ser financeiro (billing) e de segurança.
- Use o [Azure Well-Architected Framework](https://learn.microsoft.com/pt-br/azure/well-architected/) como checklist para revisar qualquer arquitetura que a IA tenha ajudado a desenhar.

- [Microsoft Reactor](https://developer.microsoft.com/en-us/reactor/) — Programa oficial de eventos e comunidades técnicas presenciais e online da Microsoft, com edições no Brasil.
- [Microsoft MVP Program](https://mvp.microsoft.com/) — Programa oficial que reconhece líderes técnicos da comunidade que compartilham conhecimento sobre produtos Microsoft, incluindo Azure.
- [r/AZURE (Reddit)](https://www.reddit.com/r/AZURE/) — Uma das maiores comunidades internacionais de discussão sobre Azure.
- [TabNews](https://www.tabnews.com.br/) — Comunidade brasileira de conteúdo técnico, com discussões frequentes sobre cloud e Azure.
- [Microsoft Learn Student Ambassadors](https://mvp.microsoft.com/en-us/studentambassadors) — Programa oficial da Microsoft para estudantes que querem liderar comunidades técnicas locais, incluindo conteúdo de Azure.

## 🎓 Certificações

- [Microsoft Certified: Azure Fundamentals (AZ-900)](https://learn.microsoft.com/en-us/credentials/certifications/azure-fundamentals/) — Nível Fundamentos: visão geral de nuvem, serviços básicos e modelo de cobrança do Azure. Ponto de partida recomendado.
- [Microsoft Certified: Azure AI Fundamentals (AI-900)](https://learn.microsoft.com/en-us/credentials/certifications/azure-ai-fundamentals/) — Nível Fundamentos: conceitos de IA e machine learning aplicados aos serviços de IA do Azure.
- [Microsoft Certified: Azure Data Fundamentals (DP-900)](https://learn.microsoft.com/en-us/credentials/certifications/azure-data-fundamentals/) — Nível Fundamentos: conceitos de dados relacionais, não relacionais e analytics no Azure.
- [Microsoft Certified: Security, Compliance, and Identity Fundamentals (SC-900)](https://learn.microsoft.com/en-us/credentials/certifications/security-compliance-and-identity-fundamentals/) — Nível Fundamentos: conceitos de segurança, conformidade e identidade no ecossistema Microsoft.
- [Microsoft Certified: Azure Administrator Associate (AZ-104)](https://learn.microsoft.com/en-us/credentials/certifications/azure-administrator/) — A certificação Associado mais procurada pelo mercado: gerenciar identidades, governança, armazenamento, redes e VMs no Azure.
- [Microsoft Certified: Azure Developer Associate (AZ-204)](https://learn.microsoft.com/en-us/credentials/certifications/azure-developer/) — Foco em desenvolvimento e deploy de aplicações e serviços nativos do Azure.
- [Microsoft Certified: Azure Security Engineer Associate (AZ-500)](https://learn.microsoft.com/en-us/credentials/certifications/azure-security-engineer/) — Foco em implementar controles de segurança, gerenciar identidade e proteger dados, aplicações e redes no Azure.
- [Microsoft Certified: Azure Network Engineer Associate (AZ-700)](https://learn.microsoft.com/en-us/credentials/certifications/azure-network-engineer-associate/) — Foco em projetar, implementar e manter a infraestrutura de rede do Azure.
- [Microsoft Certified: Azure Data Engineer Associate (DP-203)](https://learn.microsoft.com/en-us/credentials/certifications/azure-data-engineer/) — Foco em projetar e implementar pipelines de dados, ingestão e transformação no Azure.
- [Microsoft Certified: Azure Data Scientist Associate (DP-100)](https://learn.microsoft.com/en-us/credentials/certifications/azure-data-scientist/) — Foco em treinar, implantar e gerenciar modelos de machine learning no Azure Machine Learning.
- [Microsoft Certified: Azure AI Engineer Associate (AI-102)](https://learn.microsoft.com/en-us/credentials/certifications/azure-ai-engineer/) — Foco em construir e gerenciar soluções de IA usando os serviços cognitivos e o Azure AI Foundry.
- [Microsoft Certified: Azure Solutions Architect Expert (AZ-305)](https://learn.microsoft.com/en-us/credentials/certifications/azure-solutions-architect/) — Nível Expert: desenho de arquiteturas complexas de computação, rede, armazenamento e segurança no Azure.
- [Microsoft Certified: DevOps Engineer Expert (AZ-400)](https://learn.microsoft.com/en-us/credentials/certifications/devops-engineer/) — Nível Expert: automação, CI/CD e práticas de DevOps aplicadas a projetos no Azure.
- [Microsoft Certified: Windows Server Hybrid Administrator Associate (AZ-800/AZ-801)](https://learn.microsoft.com/en-us/credentials/certifications/windows-server-hybrid-administrator/) — Foco em administrar cargas de trabalho híbridas de Windows Server integradas ao Azure.
- [Guia de estudos oficial para o exame AZ-900 (Microsoft)](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/az-900) — Guia oficial de estudo para o exame AZ-900, com tópicos cobrados e recursos gratuitos recomendados.
- [Guia de estudos oficial para o exame AI-900 (Microsoft)](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/ai-900) — Guia oficial de estudo para o exame AI-900, com tópicos cobrados e recursos gratuitos recomendados.
